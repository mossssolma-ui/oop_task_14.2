# 🛒 Интернет-магазин: Базовая структура с ООП

Проект представляет собой базовую объектно-ориентированную структуру интернет-магазина, реализованную на Python. В рамках домашнего задания по курсу "Введение в ООП" созданы основные сущности для электронной коммерции: **продукты** и **категории**.

## 📋 Описание функционала

### Основные сущности

#### `Product` (Продукт)
Класс для представления отдельного товара в магазине с атрибутами:
- `name` — название продукта
- `description` — описание продукта  
- `price` — цена продукта (с поддержкой копеек)
- `quantity` — количество товара в наличии (в штуках)

#### `Category` (Категория)
Класс для группировки продуктов по категориям с атрибутами:
- `name` — название категории
- `description` — описание категории
- `products` — список объектов `Product`, относящихся к категории

### Статистика
Класс `Category` автоматически отслеживает глобальную статистику:
- **Количество категорий** — общее число созданных категорий
- **Количество товаров** — общее число всех продуктов во всех категориях

### Дополнительные возможности
- Поддержка загрузки данных из JSON-файла (`products.json`)
- Автоматическое обновление статистики при создании новых объектов

# Создание продуктов

# Создание категории

        "Смартфоны",
        "Смартфоны, как средство не только коммуникации, но и получения дополнительных функций для удобства жизни",
